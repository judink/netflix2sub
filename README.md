# 함께 자막 · 한국어 / Українська

넷플릭스의 한국어 자막과 DeepSeek가 번역한 우크라이나어 자막을 함께 보는 개인용 Chrome / Edge 확장 프로그램입니다. 한국어는 넷플릭스의 원래 위치에 두고, 우크라이나어는 영상 위쪽에 표시합니다. 별도 서버나 빌드 도구 없이 설치할 수 있습니다.

## 설치

1. Chrome 주소창에 `chrome://extensions`, Edge에서는 `edge://extensions`를 입력합니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 폴더 `C:\Users\user\Documents\netflixsub`를 선택합니다. `manifest.json`이 있는 폴더입니다.
5. 확장 아이콘을 열고 DeepSeek API 키를 입력한 뒤 **설정 저장**, **연결 테스트**를 누릅니다.
6. 넷플릭스 페이지를 새로고침하고 작품을 재생해 **한국어 자막**을 선택합니다.
7. 확장 창에서 **우크라이나어 번역 켜기**를 켭니다. 자막 파일을 읽었다면 `번역한 문장 / 전체 문장`이 표시됩니다.

API 키는 [DeepSeek 플랫폼](https://platform.deepseek.com/)에서 발급받습니다. 첫 번역에는 API 응답을 기다리는 시간이 필요합니다. 필요하면 잠시 재생을 멈춰 번역 진행률을 확인해 주세요. 우크라이나어 자막은 기본적으로 영상 위에서 4% 내려온 위치에 표시됩니다. 설정의 **화면 위에서 거리**를 0%로 설정하면 위쪽에 바로 붙습니다. 기존 아래쪽 위치 설정은 새 버전에서 사용하지 않습니다.

## 업데이트 적용

`edge://extensions` 또는 `chrome://extensions`에서 **함께 자막** 카드의 새로고침 버튼을 누른 뒤, 열려 있는 넷플릭스 페이지를 한 번 새로고침합니다. 기존 API 키와 번역 켜기 설정은 유지됩니다. 업데이트 적용 이후에는 다음 화로 넘어갈 때마다 새로고침할 필요가 없습니다.

## 작동 방식

- 페이지가 요청한 자막 응답의 **복사본**을 읽습니다. 원본 응답, 재생 요청, 한국어 자막은 수정하지 않습니다.
- `document_start`의 MAIN 스크립트에서 `fetch`와 `XMLHttpRequest`를 관찰합니다. `netflix.com` / `nflxvideo.net`의 자막 후보 응답 중 TTML/DFXP 또는 WebVTT만 전달합니다. 내부 manifest를 수동으로 변경하지 않고 관찰해 자막 URL과 작품 번호를 연결합니다.
- 언어 표기가 `ko`인 트랙을 사용합니다. 언어 표기가 없으면 한글 비율로 판별하므로 혼합 언어 트랙은 잘못 판별될 수 있습니다.
- 시작·종료 시간은 로컬에 보관합니다. 최대 24문장의 번호와 한국어 텍스트만 DeepSeek로 보내 JSON 번역 결과를 받습니다. 빠진 번호, 중복 번호, 다른 번호, 잘린 응답을 거부합니다.
- 현재 대사 주변은 최대 **4문장**의 작은 묶음으로 먼저 번역합니다. 그 뒤의 자막은 최대 **24문장**씩 미리 번역하며 한 탭에서 최대 **2개 요청을 동시에** 처리합니다. 요청 사이의 고정 대기 시간을 없앴습니다. 실제 속도는 모델, API 응답 시간과 문장 길이에 따라 달라집니다.
- 현재 재생 위치부터 앞으로 번역하고, 남은 앞부분도 순차적으로 처리합니다. 전체 트랙을 한 번에 보내는 방식이 아닙니다. 번역을 켜 두면 감지한 트랙 전체를 순차적으로 번역하므로 API 요금이 발생합니다.
- HTML `<video>`의 `currentTime`에 맞춰 우크라이나어를 표시합니다. 탐색하면 진행 중인 요청을 취소하고 새 재생 위치를 우선합니다. 번역 전인 문장에는 이전 문장의 번역을 표시하지 않습니다.
- 시리즈 자동 재생 / 다음 화 버튼으로 작품 번호가 바뀌면 이전 요청을 취소하고, 이전 화의 자막과 번역 상태를 지운 뒤 새 화를 자동으로 번역합니다. URL 변경과 재생 요소 교체를 감지합니다. 다음 화 자막이 미리 로드되었다면 작품 번호로 보관한 파일을 재사용합니다.
- 아직 새 화의 자막 응답이 없으면 관찰한 manifest의 한국어 자막 URL로 파일을 자동 확보합니다. 현재 작품에만 시도하며, HTTPS의 `netflix.com` / `nflxvideo.net` 주소로 제한합니다. 이 복구 다운로드는 번역을 켜고 API 키가 있을 때만 수행합니다. 일반 자막 트랙을 우선하고 강제 내러티브 자막은 복구 후보에서 제외합니다.
- 번역 결과는 페이지 메모리에, 반복 문장 캐시는 백그라운드 메모리에 저장합니다. 새로고침, 에피소드 전환, 서비스 워커 재시작 후에는 일부 또는 전체를 다시 번역할 수 있습니다. 영구 번역 캐시는 없습니다. 같은 트랙의 추가 구간을 받으면 이미 번역한 문장을 보존하며 합칩니다.
- 자막이 사전 로드된 전체 트랙이라면 미리 번역할 수 있습니다. 플레이어가 일부 구간만 내려준 경우 아직 받지 않았고 manifest에도 없는 구간까지 확보할 수는 없습니다.

## 키와 데이터

API 키는 `chrome.storage.local`에 저장되며 동기화하지 않습니다. 암호화된 비밀 금고가 아니므로 신뢰하는 개인 Chrome 프로필에서 사용하세요. 저장소는 `TRUSTED_CONTEXTS`로 제한하고 키를 페이지 / 콘텐츠 스크립트에 전달하지 않습니다. API 호출은 서비스 워커에서 고정된 `https://api.deepseek.com/chat/completions` 주소로만 보냅니다. 번역을 끄면 새 요청을 중지하고 진행 중인 요청을 취소합니다. 이미 전송된 요청의 과금은 취소로 되돌릴 수 없습니다.

DeepSeek에 한국어 자막 텍스트가 전송됩니다. 넷플릭스 쿠키, 비밀번호, 영상 데이터는 번역 요청에 넣지 않습니다. 연결 테스트도 실제 API 요청이며 소량 과금될 수 있습니다. 기본 모델은 공식 API 문서의 `deepseek-flash`, 옵션은 `deepseek-v4-pro`이며 thinking을 비활성화합니다.

## 감지가 안 될 때

1. 확장 설치/업데이트 뒤 넷플릭스 탭을 새로고침합니다. 이미 내려받은 파일을 소급해서 읽을 수는 없습니다.
2. 한국어 자막을 껐다 다시 켜 파일 요청이 발생하게 합니다.
3. 확장 창에서 전체 문장 수가 나타나는지 확인합니다. 숫자가 나오면 감지 성공입니다.
4. API 키 / 잔액 / 네트워크 오류를 해결한 뒤 **다시 시도**를 누릅니다.

이 버전은 넷플릭스의 공개된 공식 자막 API를 사용하는 제품이 아니라 내부 요청 형식에 의존하는 프로토타입입니다. 넷플릭스 변경, 다른 CDN 주소, 이미지 자막, 읽을 수 없는 응답 형식, iframe 플레이어에서는 감지가 안 될 수 있습니다. 자동 전환 시 manifest와 자막 요청을 모두 감지할 수 없는 경우에는 수동으로 자막을 껐다 켜거나 새로고침해야 할 수 있습니다. 브라우저의 영상만 표시하는 Picture-in-Picture에는 자막 오버레이가 들어가지 않습니다. 전체 화면은 플레이어 컨테이너 전체 화면을 대상으로 합니다.

## 검증

`node --test tests/*.test.cjs`로 시간 변환, WebVTT 파싱, 앞뒤 탐색, 중첩 자막, 번호 검증, 키 격리, 과도한 요청 차단, HTTP 오류, 요청 취소, 동시 요청 제한, 요청 등록 전 취소, 중복 없는 선행 번역 묶음을 테스트합니다.

Playwright와 Edge가 있으면 `node tests/browser.cjs <playwright 모듈 경로>`로 실제 브라우저의 TTML DOM 파싱, fetch/XHR 응답 감지, 켜기 전 API 호출 차단, 화면 위쪽 위치, 자막 동기화, 탐색, 다음 화 선행 로드 재사용, manifest 자동 복구, 동시 번역, 이전 화의 늦은 응답 차단을 합성 화면에서 검증할 수 있습니다. 이 테스트는 실제 넷플릭스나 DeepSeek에 접속하지 않습니다. 로그인된 넷플릭스 작품에서의 감지와 실제 번역 API 호출은 별도 확인이 필요합니다.
